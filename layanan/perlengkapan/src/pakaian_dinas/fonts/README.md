# Fonts for the laporan PDF

`DejaVuSansCondensed.ttf` and `DejaVuSansCondensed-Bold.ttf` are the DejaVu fonts
(Bitstream Vera derivative, free licence permitting use and redistribution, including
embedding in documents). They are the faces mPDF picks for `sans-serif`, which is what the
legacy simpelv1 laporan PDF was set in, so using them here keeps the glyph shapes and
widths of the two systems identical.

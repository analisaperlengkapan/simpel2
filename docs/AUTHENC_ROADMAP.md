# Roadmap Authenc

Daftar rencana pengembangan sistem autentikasi (Authenc):

1. **Fase 1: Fondasi (Selesai)**
   - OAuth2/OIDC core.
   - Dukungan WebAuthn/Passkeys.
   - MFA (TOTP, Email).

2. **Fase 2: Federasi & IAM (Sedang Berjalan)**
   - Integrasi LDAP/Active Directory.
   - Dashboard manajemen IAM.
   - Sinkronisasi token lintas micro-frontend.

3. **Fase 3: Kecerdasan Keamanan (Masa Depan)**
   - Adaptive Rate Limiting berbasis perilaku.
   - Deteksi anomali login dengan AI.
   - Dukungan FIDO2 tingkat lanjut.

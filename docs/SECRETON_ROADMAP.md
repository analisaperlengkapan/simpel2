# Roadmap Secreton

Daftar rencana pengembangan sistem manajemen secret (Secreton):

1. **Fase 1: Inti (Selesai)**
   - Inisialisasi, unseal, dan penyimpanan secret dasar.
   - API gRPC dan REST.

2. **Fase 2: Integrasi Cloud (Sedang Berjalan)**
   - Dukungan AWS KMS, Azure Key Vault untuk auto-unseal.
   - Integrasi Kubernetes Operator.

3. **Fase 3: Keamanan Lanjutan (Masa Depan)**
   - Post-Quantum Cryptography (PQC).
   - Dynamic secrets untuk database otomatis.
   - HSM Hardware integration penuh.
